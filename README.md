# UMS · Unified Management System Dashboard

A single-screen admin dashboard that combines Fleet, Warehouse and Real Estate management in one view. Built with plain HTML, CSS and JavaScript — no framework, no build step.

## Run

Open `index.html` in a browser.

## Files

- `index.html` — page structure
- `styles.css` — design tokens, light/dark themes, layout
- `app.js` — dashboard data (`DATA`), inline icon set, charts, live map, interactions

## Features

- Light theme by default, dark theme via the header toggle (remembered in `localStorage`)
- Live fleet map with zoom, fullscreen, vehicle filter and animated routes
- Donut, bar, combo and area charts with hover tooltips
- Designed for a 1536×1024 viewport with everything above the fold
